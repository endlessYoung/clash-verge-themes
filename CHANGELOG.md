# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] — 2026-07-25

### Changed

- README rewritten for clearer product discovery and usage (SEO-friendly)
- Removed internal design/process markdown from the public tree
- Simplified usage docs for end users

## [1.0.0] — 2026-07-25

### Added

- Five injectable themes via `dist/*.css`:
  - **Cyber Nexus** — cyan / purple glass look
  - **AI Operator** — clean blue product UI
  - **Aurora Glass** — soft spatial glass
  - **Apple Classic** — Settings-style system gray / blue
  - **Apple Liquid Glass** — frosted translucent materials
- Usage guide and theme preview screenshots
