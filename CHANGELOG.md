# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-07-25

First stable release on `main`.

### Added

- Five injectable themes via `dist/*.css`:
  - **Cyber Nexus** — Neural OS (cyan / purple glass)
  - **AI Operator** — Agent desk (Linear / Cursor blue zinc)
  - **Aurora Glass** — Spatial glass
  - **Apple Classic** — iOS Settings HIG
  - **Apple Liquid Glass** — Frosted liquid materials
- Specs 12–15.1 design history under `specs/`
- Usage docs and preview screenshots

### Notes

- Pin jsDelivr imports to a **commit hash** or **`v1.0.0` tag**, not `@develop` / `@main` branch aliases.
- Status colors remain locked in `core/tokens.css`.
