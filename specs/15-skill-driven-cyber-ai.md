# Spec 15 — Skill-driven Cyber + AI Operator redesign

Date: 2026-07-25  
Skills: `cyber-nexus-ui-designer` · `ai-operator-ui-designer` · `frontend-design`

## Design theses (frontend-design pass)

### Cyber Nexus — “Neural OS”
- Subject: AI infrastructure control surface
- Signature: **cyan as information signal** on layered void glass; soft radius; mono only for telemetry
- Risk taken: drop gaming HUD (chamfer / magenta / Orbitron / CRT) entirely — skill forbids decorative cyberpunk

### AI Operator — “Agent desk”
- Subject: autonomous operator workspace (Linear / Cursor / OpenAI Operator vernacular)
- Signature: **system blue `#2563EB`** selected rail + zinc surfaces; mono only on traffic digits
- Risk taken: drop phosphor terminal green / `$` cosplay — skill forbids cyberpunk & gaming

## Differentiation acceptance

- Cyber ≠ green neon HUD; reads cyan/purple neural glass
- AI Operator ≠ terminal; reads clean blue product UI
- Side-by-side: different primary hue family (cyan vs blue) and different material (glass glow vs flat zinc)
